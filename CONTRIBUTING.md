# Contributing to Chakula Konnect

Thank you for contributing! Please follow these steps to keep our repo organized.

## 1. Create an Issue
- Every task must have an Issue before starting.
- Assign yourself to the issue you are working on.

## 2. Branching
- Do not push directly to main.
- Create a new branch for every task:
  - Naming convention: 
    - feature/backend-auth
    - feature/frontend-marketplace
    - docs/user-personas

## 3. Committing
- Keep commits small and clear.
- Example: `git commit -m "Backend: Initialize Express project"`

## 4. Pull Requests (PRs)
- Push your branch to GitHub.
- Open a PR to `main`.
- Link the PR to the relevant Issue: `Closes #issue_number`
- Wait for review before merging.

## 5. Folder Guidelines
- frontend/ → React code
- backend/ → Express + PostgreSQL code
- docs/ → PRD, user personas, diagrams, other documentation

## 6. Reviews
- Team lead reviews all PRs before merging.
- Merge only after approval.

Thank you for helping keep the project organized!
