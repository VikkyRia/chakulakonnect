# Chakula Konnect

A digital platform for affordable, nutritious food access, connecting smallholder farmers, vendors, and consumers.  
Aligned with **SDG 2 – Zero Hunger**.

---

## Project Overview

Chakula Konnect aims to:

- Reduce food waste by connecting surplus food from farmers and vendors to consumers  
- Improve access to nutritious, affordable food for households  
- Support smallholder farmers with stable market opportunities  

The platform includes:

- **Frontend**: React web application  
- **Backend**: Express.js with PostgreSQL database  
- **Documentation**: PRD, user personas, diagrams, and other project docs
